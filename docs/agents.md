# Для AI-агентов

Краткая и точная шпаргалка для coding-агентов (Claude Code, Cursor, Copilot...), которые работают с
библиотекой. Тот же текст (на английском — так надёжнее для агентов) поставляется в npm-пакете как
`AGENTS.md` (лежит в `node_modules/@alt-point/active-models/`), а индекс
[`llms.txt`](https://alt-point.github.io/active-models/llms.txt) публикуется рядом с этим сайтом.

Подсказка: сошлитесь на него из `CLAUDE.md` / `AGENTS.md` своего проекта:

```md
Перед работой с моделями прочитай node_modules/@alt-point/active-models/AGENTS.md.
```
