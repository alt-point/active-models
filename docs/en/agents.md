# For AI agents

A compact, accurate cheat sheet for coding agents (Claude Code, Cursor, Copilot...) using this library.
The same text ships inside the npm package as `AGENTS.md` (so it's found in `node_modules/@alt-point/active-models/`),
and an [`llms.txt`](https://alt-point.github.io/active-models/llms.txt) index is published next to this site.

Tip: point your agent at it from your own project's `CLAUDE.md` / `AGENTS.md`:

```md
When working with models, read node_modules/@alt-point/active-models/AGENTS.md first.
```
